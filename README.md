# 🏎️ F1 Telemetry Analyzer

### Exploring Formula 1 Performance Through Data & Engineering

An interactive Formula 1 telemetry analysis application developed with Python. The project focuses on visualizing racing data, comparing driver performance, and exploring data-driven approaches to motorsport engineering.

---

## 📌 About the Project

F1 Telemetry Analyzer is a personal engineering project designed to explore how data analysis and software development can contribute to understanding Formula 1 performance.

The application provides interactive visualizations and analytical tools to examine lap times, compare drivers, and explore telemetry-related data.

This project represents my first steps towards combining software engineering, data science, and motorsport.

## 🚀 Features

- **Lap Time Analysis:** Analyze and compare lap times.
- **Driver Comparison:** Compare performance between multiple drivers.
- **Telemetry Visualization:** Explore racing data through interactive graphs.
- **Performance Analysis:** Identify performance differences and trends.
- **Interactive Dashboard:** Navigate analysis through a Streamlit interface.
- **Data Visualization:** Generate interactive charts using Plotly.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Main programming language |
| Pandas | Data manipulation and analysis |
| NumPy | Numerical computations |
| Plotly | Interactive visualizations |
| Streamlit | Interactive web application |

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/mf1062005-svg/F1-Telemetry-Analyzer.git
```

Navigate to the project directory:

```bash
cd F1-Telemetry-Analyzer
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

*Adjust the entry-point filename if your main application file has a different name.*
